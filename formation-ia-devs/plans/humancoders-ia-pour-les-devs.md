# Formation IA pour les devs – Maîtrisez l'IA pour coder - Human Coders

**Source:** https://www.humancoders.com/formations/ia-pour-les-devs  
**Duration:** 2 days  
**Satisfaction:** 4.4/5 (36 avis)

## Description

Cette formation sur l'état de l'art des outils IA pour développeurs vous apportera une maîtrise des dernières technologies d'IA appliquées au développement.

### Au cours de cette journée, vous apprendrez à :

- choisir les outils et modèles adaptés à vos besoins en fonction de vos objectifs (performance, qualité, vitesse, etc.) et contraintes (sécurité des données, RGPD, etc.),
- utiliser des outils d'assistance pour
  - la génération de code (comme Cursor, Copilot, Zed, Tabnine, CodeWhisperer)
  - la documentation
  - le débogage
  - la revue de code et
  - les tests unitaires automatisés (DeepCode).

Grâce à des cas d'usage concrets et des ateliers pratiques, vous optimiserez vos workflows de développement et intégrerez l'IA tout au long du cycle de vie d'une application pour gagner en efficacité et en qualité.

### Public

Développeur·se·s souhaitant intégrer des outils d'IA dans leur workflow pour gagner en efficacité et améliorer la qualité de leur code.

### Pré-requis

- Maîtrise des bases de la programmation (dans n'importe quel langage)
- Expérience avec des environnements de développement (IDE, Git, etc.)
- Ordinateur portable à apporter

## Programme

### Jour 1 : L'IA dans le workflow du dev

#### Découvertes des cas d'usages IA pour les développeurs
- Tendances actuelles de l'IA pour les développeurs
- Comment les développeurs peuvent-ils utiliser l'IA ?

#### Impact de l'IA sur le workflow de développement
- Collaboration IA / Développeur
- Intégration dans les environnements de travail existant

#### Assistance à la génération de code
- Parler à l'IA pour qu'elle vous suggère du code
- Les limites du code généré par IA
- Outils et workflow de génération de code grâce à l'IA (Cursor, Copilot, Tabnine, Windsurf)

#### Documentation du code avec l'IA
- Laissez l'IA écrire la doc !
- Outils et workflow de génération de documentation avec de l'IA

#### L'IA pour la réalisation de tests unitaires
- Automatiser la création de ses tests unitaires
- Que vaut l'IA pour réaliser ses tests ?
- Outils et workflow pour les tests unitaires avec l'IA (DeepCode, Kite)

***Mises en pratique*** :

- *Génération d'une fonction simple avec plusieurs outils IA, comparer leurs propositions et identifier leurs limites*
- *Rédaction de la documentation d'un fichier source par l'IA, puis correction en binôme*
- *Enrichissement d'une base de code existante en générant des tests avec l'IA, puis vérification*

---

### Jour 2 : L'IA pour la qualité, la sécurité et la collaboration

#### Amélioration du processus de développement
- Débogage assisté par IA
- Détection des vulnérabilités
- Optimisation du code
- Revue de code assistée par IA (Codacy, SonarQube)

#### Enjeux éthiques et réglementaires
- Confidentialité du code et hébergement des outils IA
- IA dans les environnements réglementés : précautions et bonnes pratiques

***Mises en pratique*** :

- *Projet fil rouge : développement de fonctionnalités à une appli existante (front ou back), en utilisant l'IA à chaque étape du cycle de dev (code, tests, doc, revue)*
- *Documentation de ses choix d'outils IA et identification de leurs apports ou limites dans un contexte réel*
- *Présentation en groupe de la fonctionnalité développée et retour critique sur la collaboration humain / IA*

## Points clés à retenir pour ma formation

### Ce qui fonctionne bien dans ce plan:
- Approche par **étapes du cycle dev**: code → tests → doc → revue
- Projets fil rouge sur appli existante (plus réaliste que partir de zéro)
- Comparaison d'outils multiples (pas enfermé dans un seul)
- Temps de retour critique humain/IA

### Ce que je veux adapter:
- **Outil principal: OpenCode** (TUI agentique transparent)
- Vue comparative par **catégories**:
  - TUI agents autonomes: OpenCode, Claude Code, Codex, Gemini CLI
  - Assistants IDE: Cursor, Copilot, Cline, Roo Code
- Ajouter **MCP** et son écosystème
- Ajouter **AGENTS.md** et conventions équipe
- Ajouter **Ralph Loop** et workflows autonomes
- Ajouter **gestion des coûts**: modèles frugaux (Gemini, GLM-4.7, Qwen)
- Ajouter **screenshot playwright** (pas besoin d'image!)
- Ajouter **Docker + docker-compose patterns**
- Ajouter **analyse de runs existants** ("qu'aurait-on pu améliorer?)
- Ajouter **tool calling transparency** (comprendre ce que fait l'agent)
- Ajouter **bonnes pratiques équipe**: conventions IA, tensions engendrées

### Projet fil rouge potentiel:
- github.com/betagouv/comparia (FastAPI + Svelte)
- Projets simples: jeu vidéo Bevy (Rust), quiz infographie Marne
- Survey initiale: langage préféré, outils contemplés, accès API?

## Idées d'exercices (projet fil rouge)

1. **Survey initiale**: langage préféré, outils déjà contemplés, accès API?
2. **Comparaison tools**: même tâche simple sur plusieurs outils, comparer les outputs
3. **TP context forgetting**: montrer un cas où l'agent "oublie" le contexte
4. **TP AGENTS.md**: créer un fichier de conventions pour un projet
5. **TP Ralph Loop**: lancer un agent autonome sur une tâche longue
6. **TP screenshot playwright**: comprendre que pas besoin d'image
7. **TP analyse de run**: commenter un "run" de qqun, identifier améliorations
8. **TP frugal AI**: même tâche avec modèle premium vs modèle frugal
